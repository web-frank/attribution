# attribution

[English](README.md) · **Русский**

8 моделей маркетинговой атрибуции в ~1 КБ

**714 байт min+gzip** (1 372 байта minified ESM). Без зависимостей в рантайме. ESM, CommonJS и типы TypeScript.

```js
import { credits, attribute } from 'attribution';
const split = credits([{ channel: 'search', paid: true }, { channel: 'direct' }], 'u_shape');
const winner = attribute(split.map(c => c.visit), 'last_paid');
```

`credits(visits, model, customWeights?)` возвращает `{ visit, share }[]`. Сумма долей равна 1. Одноканальные модели возвращают только победившую запись; остальные — по одной записи на визит, включая нулевые доли. `attribute(visits, model, customWeights?)` возвращает визит с наибольшей долей (при равенстве — более поздний), либо `null` для пустого пути. Пустые пути не дают кредитов. Визиты и их дополнительные поля сохраняются по ссылке и никогда не мутируются.

| Аргумент / опция | По умолчанию | Поведение |
| --- | --- | --- |
| `visits` | Обязателен | Массив от старых к новым; у каждого визита `channel: string` и опционально `paid: boolean \| number`. Дополнительные поля разрешены и сохраняются в TypeScript. |
| `model` | Обязателен | Одно из восьми имён ниже. |
| `customWeights` | `[40, 20, 40]` | `[первый, все средние визиты, последний]`. Средний вес делится поровну; итог нормируется. Используется только моделью `custom`. |

| Модель | Правило кредита |
| --- | --- |
| `first` | 100% первому визиту. |
| `last` | 100% последнему визиту. |
| `last_paid` | Последний платный визит; иначе последний непрямой; иначе последний. `direct` чувствителен к регистру. |
| `linear` | Равные доли. |
| `u_shape` | 40% первому, 20% между средними, 40% последнему. |
| `time_decay` | Веса позиций 1, 2, …, n. |
| `reverse_decay` | Веса позиций n, …, 2, 1. |
| `custom` | Пользовательские веса позиций. |

С одним визитом его доля равна 1. С двумя визитами позиционные модели нормируют только первый и последний веса. Неверные имена моделей бросают `TypeError`. Пользовательские веса — три конечных неотрицательных числа, хотя бы одно положительное, и дающих положительный кредит доступным позициям; иначе бросают `RangeError` для непустых путей. `MODELS` и `isModel(value)` тоже экспортируются.

## Чего не делает

Не собирает данные, не сортирует визиты, не фильтрует окна конверсии, не идентифицирует посетителей, не грузит базы и не применяет правила конкретной CRM. Готовый хронологический путь передавайте сами. Затухание — по порядковой позиции, а не по прошедшему времени или экспоненциальному периоду полураспада. Доли и денежные суммы не округляет.

## Разработка

`npm ci`, `npm test`, `npm run build`. Включает оригинальные тесты моделей из roitrail, адаптированные под минимальные самостоятельные визиты, плюс краевые случаи API. Сборка печатает размер minified ESM и gzip (Node 22, уровень 9), без tree shaking. MIT © 2026 Daniel Raskopin.

Часть roitrail → https://github.com/web-frank/roitrail

## Живое демо

Откройте [`demo/index.html`](demo/index.html) прямо в браузере. Самодостаточный файл включает библиотеку и работает офлайн, без сервера и сборки. `npm run build` обновляет встроенную библиотеку из исходника.
